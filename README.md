# VHDL_2 - Digital Logic Circuit Design

This repository contains the second assignment for the Digital Logic Circuit Design course.

## Contents
- `vhd/` – VHDL source code
- `circuit/` – Logisim circuit files
- `Digital_Logic_Circuit_Design_Report.pdf` – Assignment report with simulation results and explanations

## Tools
- VHDL
- Logisim-evolution
- Questa Simulator

## Description
The assignment focuses on implementing and simulating digital logic circuits, including a JK Flip-Flop, using VHDL and Logisim.
